# College FAQ Chatbot

A Python-based FAQ chatbot developed for CodeAlpha Internship Task 2. It answers college-related questions using Natural Language Processing (NLP) and text similarity techniques.

## Features
- Text preprocessing using NLTK.
- FAQ matching using TF-IDF and cosine similarity.
- Questions and answers stored in CSV files.
- Handling of unknown or low-confidence questions.
- Interactive interface built with Streamlit.
- Unit tests and evaluation scripts.

## Technologies Used
- Python
- NLTK
- TF-IDF
- Cosine Similarity
- CSV
- Streamlit

## Run Locally
1. Clone this repository.
2. Open the `faq-chatbot` folder.
3. Install the dependencies:

   `pip install -r requirements.txt`

4. Start the application:

   `python -m streamlit run app.py`

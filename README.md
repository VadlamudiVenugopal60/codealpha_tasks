# CodeAlpha Internship Projects

This repository contains projects developed as part of my CodeAlpha Internship.

## Projects

### Task 2: College FAQ Chatbot

A Python-based FAQ chatbot that answers college-related questions using Natural Language Processing (NLP) and text similarity techniques.

**Features:**

- Text preprocessing using NLTK.
- FAQ matching using TF-IDF and cosine similarity.
- Questions and answers stored in CSV files.
- Handling of unknown or low-confidence questions.
- Interactive interface built with Streamlit.
- Unit tests and evaluation scripts.

**Technologies Used:**

- Python
- NLTK
- TF-IDF
- Cosine Similarity
- CSV
- Streamlit

**Project Folder:** `faq-chatbot`

### Task 4: Object Detection and Tracking

A real-time object detection and tracking application developed using Python, OpenCV, and YOLO.

**Features:**

- Real-time video input using webcam or video files.
- Object detection using a pre-trained YOLO model.
- Frame-by-frame object detection.
- Object tracking using ByteTrack.
- Bounding boxes and object labels.
- Unique tracking IDs for detected objects.
- Real-time FPS and object count display.

**Technologies Used:**

- Python
- OpenCV
- Ultralytics YOLO
- ByteTrack

**Project Folder:** `CodeAlpha_ObjectDetectionTracking`
